# Project prompt

ralph-loop automatically wraps this file with its own harness prompt
(TDD discipline, one-commit-per-iteration, the stop condition, and the
completion-promise reporting format) before every iteration — you don't
need to repeat any of that here. Just describe *this project's* goal and
plan below.

## Goal

Describe the overall outcome this project is working towards.

## Plan

Point at this project's own plan/spec document (e.g. PLAN.md — replace
with whatever this project actually calls it, or inline the plan directly
here) and describe the order milestones should be tackled in.

## Verification

Describe how completion should be verified for this project specifically
— e.g. "run `npm test` and `npm run build`, both must be clean" or
"run `go test ./...` and `go vet ./...`".
